# ⚠️ Lưu ý

- 📱 Hiệu năng giả lập phụ thuộc vào **CPU, GPU và RAM của thiết bị**.
- 🎮 Không phải game nào cũng chạy tốt trên tất cả các giả lập.
- 🔄 Nên cập nhật giả lập và driver khi gặp lỗi.
- 🎨 Với thiết bị Snapdragon dùng GPU Adreno, có thể thử nhiều phiên bản **Turnip / Adreno Driver** để tìm bản phù hợp nhất.
- 💾 Nên sao lưu **save game** trước khi cập nhật hoặc đổi giả lập.
- 📥 Chỉ nên sử dụng game, firmware và các tệp hệ thống mà bạn có quyền sử dụng.
