# 📌 Lưu ý

- 🎮 Hiệu năng phụ thuộc vào **CPU / GPU / RAM** của thiết bị.
- ⚙️ Một số game có thể cần thiết lập riêng để chạy ổn định.
- 🎨 Với GPU **Qualcomm Adreno**, có thể thử các phiên bản **Turnip Driver** khác nhau.
- 💾 Nên sao lưu Save trước khi cập nhật hoặc thay đổi giả lập.
- 📱 Không phải tất cả game đều tương thích với mọi phiên bản giả lập.
- ⚠️ Chỉ sử dụng game, firmware và các tệp hệ thống mà bạn có quyền sử dụng.
